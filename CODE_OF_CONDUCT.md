# Moxie Code of Conduct

Moxie is a club project with many members contributing together. To keep collaboration smooth and respectful, everyone is expected to follow these rules.

## Expected Behavior

- Be respectful and constructive in comments, reviews, and discussions.
- Give feedback on the work, not the person.
- Assume good intent — ask questions before assuming someone did something wrong.
- Credit others' contributions fairly.
- Keep discussions on GitHub (issues/PRs) so context stays visible to the whole team, not just in private chats.

## Not Acceptable

- Personal attacks, insults, or disrespectful language toward any member.
- Dismissing or mocking someone's idea, question, or contribution.
- Merging your own PR without review, or bypassing agreed rules in [CONTRIBUTING.md](./CONTRIBUTING.md).
- Taking credit for someone else's work.
- Sharing private club information outside the team without permission.

## Reporting Issues

If someone isn't following these guidelines, or you're facing a conflict you can't resolve directly, reach out to the Moxie core team/organizers privately.

## Scope

This applies to all Moxie spaces: this GitHub repo (issues, PRs, comments), and any club communication channels (WhatsApp, meetings, etc.) related to this project.
