# Moxie

**Moxie** is the technology club of **Muzaffarpur Institute of Technology (MIT), Muzaffarpur)**.

This repository contains the work for building the official Moxie website.

> 🚧 **Project Status:** Early planning and research stage.

---

## 🚀 About the Project

The goal of the Moxie website is to create a central online presence for the club where students, members, visitors, recruiters, sponsors, and other organizations can learn about Moxie and its activities.

The website will be developed collaboratively by Moxie members.

Before development begins, we are first defining the requirements and researching existing college technical club websites.

---

## 🛠️ Technology Stack

The current planned technology stack is:

| Technology       | Purpose                            |
| ---------------- | ---------------------------------- |
| **Next.js**      | Web application framework          |
| **React**        | Frontend UI                        |
| **TypeScript**   | Type-safe development              |
| **Tailwind CSS** | Styling                            |
| **shadcn/ui**    | UI components                      |
| **NestJS**       | Backend framework                  |
| **MongoDB**      | Database                           |
| **Clerk**        | Authentication and user management |

> The exact architecture and implementation details may evolve as the project progresses.

## 📋 Current Work

The project is currently focused on requirements and research.

### Issue #1 — Requirements

Define what the Moxie website should accomplish, including:

* Problems the website should solve
* User types
* User stories
* Must-have features
* Nice-to-have features
* Required content
* Success criteria
* Open questions

### Issue #2 — Website Research

Research technical club websites from:

* IITs
* NITs
* BITS Pilani
* DTU
* NSUT
* Other reputed colleges and universities

The research will help us understand common patterns, useful features, and good examples before designing the Moxie website.

## 🌱 Project Stage

Moxie is currently in the early stages of planning.

The following are **not finalized yet**:

* Folder structure
* Frontend architecture
* Backend architecture
* API design
* Database schemas
* User roles and permissions
* Page structure
* UI design
* Deployment architecture
* Hosting
* CI/CD

These decisions will be made as the requirements and technical planning are completed.

**Do not assume or introduce major architectural decisions without discussing them with the team.**
