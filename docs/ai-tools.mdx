# AI Development Tools

We evaluate and utilize modern AI-powered tools across software development stages to accelerate development, improve code quality, and automate repetitive tasks.

> **Living Document**: Tools are evaluated periodically and updated as better alternatives become available.

---

## Catalog of Evaluated Tools

### 1. Google Stitch (UI/UX Design)
- **Website**: [stitch.withgoogle.com](https://stitch.withgoogle.com/)
- **Purpose**: AI-powered UI/UX interface design and concept generation.
- **Use Cases**:
  - Generating initial screen concepts from prompts.
  - Exploring layout options and visual design directions.
  - Rapid prototyping prior to frontend coding.

### 2. Google Antigravity (AI IDE & Agentic Development)
- **Website**: [antigravity.google](https://antigravity.google/)
- **Purpose**: Agentic development environment for pair programming with AI agents.
- **Use Cases**:
  - Codebase analysis and refactoring.
  - Implementing feature specifications.
  - Debugging errors and running verification pipelines.

### 3. Freebuff (Free AI Coding Platform)
- **Website**: [freebuff.com](https://freebuff.com/)
- **Purpose**: Free AI-powered development environment and coding agent platform.
- **Use Cases**:
  - AI-assisted coding without subscription requirements.
  - Rapid code snippet prototyping.
