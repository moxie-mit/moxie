# Project Requirements Overview

This document summarizes the requirements for the Moxie club website. For the complete, unedited specification document, inspect [`docs/Requirements.md`](file:///d:/PROJECTS/moxie/docs/Requirements.md).

---

## User Personas

| User Type | Who They Are | Goal | Device / Access |
| :--- | :--- | :--- | :--- |
| **Prospective Member** | MIT Muzaffarpur student | Learn about Moxie, browse past events, sign up for events or recruitment | Mostly Mobile |
| **Event Participant** | Event attendee | Register for events, receive QR ticket, download verifiable certificate | Mostly Mobile |
| **Club Admin / Core** | Moxie leadership & organizers | Create/manage events, scan QR attendance, issue certificates, track records | Desktop / Mobile |
| **Visitor / Sponsor** | Faculty, external sponsors, judges | Review club achievements, stats, verify certificates, contact team | Desktop / Mobile |

---

## Must-Have Feature Roadmap

1. **Homepage**: Showcase club mission, upcoming events, key statistics, and contact info.
2. **Event Catalog & Registration**: Browse active/past events, online registration with duplicate prevention.
3. **QR Code Attendance System**: Confirmation email/screen with QR ticket; venue check-in scanner for admins.
4. **Verifiable Certificates**: Automated bulk certificate generation for attendees and public verification portal.
5. **Admin Participant Database**: Central, searchable history of attendees across all past events.
6. **Authentication & Authorization**: Role-based access control ensuring admin features are protected.
