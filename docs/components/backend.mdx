## Bootstrap & Pipeline Configuration (`src/main.ts`)

```typescript
import { ValidationPipe } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { HttpExceptionFilter } from './common/http-exception.filter';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // Enable global validation pipe for DTO inputs
  app.useGlobalPipes(
    new ValidationPipe({
      whitelist: true,
      transform: true,
    }),
  );

  // Enable global exception filter for normalized JSON errors
  app.useGlobalFilters(new HttpExceptionFilter());

  const port = process.env.PORT ?? 3001;
  await app.listen(port);
}
bootstrap();
```

---

## Key Modules & Components

1. **`AppModule`**: Connects Mongoose using `process.env.MONGODB_URI` and imports `UsersModule`.
2. **`ClerkAuthGuard`**: Implements NestJS `CanActivate`, retrieving request auth status via `getAuth(request)`. Throws `UnauthorizedException` if `userId` is missing.
3. **`HttpExceptionFilter`**: Intercepts unhandled HTTP exceptions and formats uniform error JSON objects:
   ```json
   {
     "statusCode": 401,
     "timestamp": "2026-08-24T02:50:00.000Z",
     "path": "/auth/me",
     "message": "Missing or invalid authentication token"
   }
   ```
