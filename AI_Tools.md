# AI Development Tools

We use and evaluate modern AI-powered tools across different stages of software development. The purpose is to help the team move faster, improve quality, and automate repetitive development work.

> **Note:** This is a living list. Tools can be added, removed, or replaced as better alternatives become available.

---

## 🎨 UI/UX Design

### Google Stitch

**Website:** https://stitch.withgoogle.com/

**Purpose:** AI-powered UI/UX design and interface generation.

**Use it for:**

* Generating UI concepts from prompts
* Exploring different layouts and design directions
* Rapidly prototyping screens
* Turning ideas into visual interfaces
* Iterating on UI designs before implementation

---

## 🧑‍💻 AI IDE / Development

### Google Antigravity

**Website:** https://antigravity.google/

**Purpose:** Agentic development environment for building software with AI agents.

**Use it for:**

* AI-assisted development
* Understanding and modifying codebases
* Implementing features
* Debugging
* Running development tasks
* Working with multiple agents
* Browser-based verification and UI workflows

## 🔄 Maintaining This List

When adding a tool:

1. Add it under the appropriate category.
2. Use the **Tool Entry Template** above.
3. Keep the description short and focused on how the team can use it.
4. Prefer official websites.
5. Remove tools that are no longer useful or maintained.
6. Re-evaluate tools periodically as the AI development ecosystem changes.
